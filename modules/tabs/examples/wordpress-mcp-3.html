Abilities API im WordPress-Kern

Seit WordPress 6.9 registrieren Plugins Fähigkeiten mit wp_register_ability(), jeweils mit Ein- und Ausgabeschema und einer permission_callback. Per REST sind sie unter wp-abilities/v1 erreichbar.

Was das für euch bedeutet: Funktionen eurer Website lassen sich einheitlich beschreiben und für KI-Clients freigeben. Weil die API Teil des Kerns ist, wird sie mit jedem WordPress-Update gepflegt.

MCP Adapter und Standard-Server

Der MCP Adapter (Version 0.7.0, Oktober 2026) setzt auf der Abilities API auf, unterstützt die MCP-Spezifikation vom 28.07.2026 und verlangt WordPress 6.9 und PHP 7.4. Im Standard-Server erreicht der Client freigegebene Abilities über drei Meta-Werkzeuge: finden, beschreiben, ausführen.

Was das für euch bedeutet: Sichtbar wird nur, was mit meta.mcp.public freigegeben ist. Für Tests reicht das. Eigene Server bieten Abilities direkt als Werkzeuge an, was Agenten die Arbeit erleichtert.

Anmeldung mit OAuth 2.1

Die MCP-Spezifikation macht Autorisierung optional. Wer sie über HTTP anbietet, soll OAuth 2.1 nutzen: Der Server veröffentlicht Protected Resource Metadata (RFC 9728), Clients nutzen PKCE und schicken das Token in jedem Request im Authorization-Header.

Was das für euch bedeutet: Ohne gültiges Token beantwortet ein geschützter Server keine Anfrage. Der MCP Adapter selbst arbeitet mit WordPress-Anwendungspasswörtern über den Proxy @automattic/mcp-wordpress-remote, für Produktivsysteme setzt 360VIER auf OAuth.

Claude und ChatGPT anbinden

Claude bindet entfernte MCP-Server als benutzerdefinierte Connectors ein, in allen Tarifen. In Team- und Enterprise-Konten fügen Owner den Connector hinzu, danach meldet sich jedes Mitglied selbst an. ChatGPT unterstützt eigene MCP-Server über den Entwicklermodus.

Was das für euch bedeutet: Claude verbindet sich aus der Cloud von Anthropic, nicht vom eigenen Rechner. Eine Staging-Seite hinter VPN ist dann nicht erreichbar. Schreibende Werkzeuge sollten nur Entwürfe erzeugen, weil die Recherche-Funktion Werkzeuge ohne erneute Bestätigung aufrufen kann.
