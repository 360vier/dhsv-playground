Propstack und WordPress verbinden: Plugin, OpenImmo oder API

Für eine Objektliste mit Detailseiten genügt oft ein Plugin. Projektvermarktung, eigene Suche oder ein Login-Bereich brauchen die API. Die drei Wege im Überblick:

Plugin „Connector for Propstack“ oder OpenImmo

Das Plugin importiert Objekte über die offizielle API als WordPress-Inhalte mit eigener URL, die kostenlose Version zeigt bis zu zehn Objekte in der Liste. Alternativ hinterlegt ihr die Website in Propstack als Portal und empfangt Objekte per OpenImmo. Projekte überträgt Propstack nur über die API.

Middleware mit n8n oder Make

Passt, wenn Ereignisse aus Propstack weitere Systeme anstoßen sollen, etwa eine Slack-Nachricht bei Preisänderung oder ein Newsletter-Eintrag nach einer Anfrage, zum Beispiel in Brevo. Die Darstellung der Objekte auf der Website löst Middleware nicht.

Eigene Anbindung an die Propstack API

Nötig bei eigener Objektsuche, Projektseiten mit Einheiten, mehrsprachigen Exposés oder einem Kundenbereich. 360VIER baut eine WordPress-Erweiterung, die Objekte zwischenspeichert, Webhooks verarbeitet und Anfragen mit Quelle und Einwilligung übergibt. Grundlagen: API-Integrationen.

Welche Immobiliendaten fließen zwischen Propstack und WordPress?

Objekte und Einheiten

Von Propstack nach WordPress, beim ersten Import vollständig, danach per Webhook bei jeder Änderung.

Projekte

„Über-Objekte“ mit mehreren Einheiten, nur über die API, jeweils mit den zugehörigen Einheiten.

Bilder, Dokumente, Übersetzungen

Zusammen mit dem Objekt. Objekt- und Lagebeschreibung kommen über den Parameter locale auch auf Englisch.

Interessenten-Anfragen

Von WordPress nach Propstack, direkt beim Absenden, als Kontakt mit Objektbezug und UTM-Parametern.

Suchprofile und Eigentümer

Aus Suchauftrags- und Bewertungsformularen der Website als Kontakt mit Suchprofil oder Eigentümer-Anfrage.

Status und Archivierung

Verkaufte oder archivierte Objekte verschwinden von der Website, sobald Propstack den Status ändert.

Propstack API und Webhooks: Schlüssel, Limits, Stolperstellen

  • Schnittstelle: REST-API V1 unter https://api.propstack.de/v1, Objekte über GET /units, Kontakte über POST /contacts. Eine API V2 für große Datenmengen ist laut Propstack noch in Arbeit und bildet nicht alle V1-Endpunkte ab.
  • API-Schlüssel: im Header X-API-KEY. Admins legen Schlüssel unter Verwaltung → API-Schlüssel an und vergeben dort Berechtigungen. Propstack stellt Dienstleistern keine Schlüssel aus, euer Büro erzeugt ihn.
  • Limits: Listen werden mit page und per geblättert. Propstack rät, per höchstens auf 500 zu setzen, um Timeouts zu vermeiden. Abruflimits pro Minute veröffentlicht Propstack nicht.
  • Webhooks: 18 Ereignisse, darunter property_created, property_updated und client_created. Bei hinterlegtem Secret steckt eine HMAC-SHA-256-Signatur im Header X-Propstack-Signature.
  • Stolperstelle: Beim Löschen eines Objekts feuert Propstack kein eigenes Ereignis, sondern property_updated. Prüft die Erweiterung Status und Archivierung nicht, bleiben gelöschte Objekte online.

KI-Agenten für Maklerbüros mit Propstack: Objektfragen beantworten, Anfragen zuordnen

Ein KI-Chatbot auf der Website beantwortet Fragen zu Objekten mit den aktuellen Daten aus Propstack: Ist die Wohnung noch frei, gibt es einen Stellplatz, wann ist die nächste Besichtigung. Bei einer konkreten Anfrage legt er den Kontakt mit Objektbezug und Einwilligungsstatus an.

Im Büro liest ein zweiter Agent neue Anfragen, gleicht sie mit Suchprofilen ab und schlägt passende Objekte vor. Ein Mensch gibt jede Antwort frei. Für Claude und ChatGPT gibt es einen MCP-Server für Propstack als Community-Projekt; wie MCP mit WordPress funktioniert, steht unter WordPress-MCP.

Häufige Fragen zu Propstack und WordPress

Gibt es ein fertiges WordPress-Plugin für Propstack?

Ja. „Connector for Propstack“ importiert Objekte über die offizielle API als WordPress-Inhalte mit eigener URL und eigenem Title-Tag. Für Projekte mit Einheiten, eigene Suchfilter oder einen Kundenbereich reicht ein Plugin meist nicht, dann folgt die eigene API-Anbindung.

Kostet die Propstack API extra?

Nein, Propstack berechnet für den API-Zugriff nach eigener Aussage nichts. Aufwand entsteht bei der Entwicklung auf WordPress-Seite. Er hängt ab von der Zahl der Objektarten, Projekten mit Einheiten, Mehrsprachigkeit, Formularen und einem möglichen Kundenbereich. 360VIER schätzt ihn nach einem kurzen Blick auf euren Account.

Wo finde ich den Propstack-API-Schlüssel?

In Propstack unter Verwaltung → API-Schlüssel. Dort legt ein Admin den Schlüssel an, vergibt Berechtigungen und sieht die Logs der Zugriffe. Propstack gibt Schlüssel nicht an Agenturen heraus, euer Büro erzeugt ihn und übergibt ihn sicher an den Dienstleister.

Wie aktuell sind die Objekte auf der Website?

Mit Webhooks sofort. Propstack meldet jede Änderung an einem Objekt an WordPress, die Website aktualisiert dann nur dieses Objekt. Ein nächtlicher Abgleich fängt verpasste Meldungen ab. Bei OpenImmo hängt die Aktualität davon ab, wie oft Propstack an das hinterlegte Portal exportiert.
Wie kommen Anfragen von der Website in Propstack?

Auf zwei dokumentierten Wegen. Die Website schickt eine E-Mail an die mit Propstack verbundene Adresse, mit OpenImmo-XML im Anhang oder mit HTML-Feldern im Container ps-kontaktanfrage. Oder WordPress legt den Kontakt direkt per API an, dann auch mit DSGVO-Status und eigenen Feldern.

OpenImmo oder API: was ist besser?

Für eine Website mit eigener Suche und Projektvermarktung die API. OpenImmo ist schnell eingerichtet, wenn ein Plugin die Daten empfängt, und funktioniert wie der Export an Immobilienportale. Die API liefert zusätzlich Projekte, Übersetzungen, Webhooks und den Rückweg für Anfragen.

Können wir von onOffice zu Propstack wechseln, ohne die Website neu zu bauen?

In vielen Fällen ja. Wenn die Website Objekte in einer eigenen Zwischenschicht speichert, tauscht ihr nur die Anbindung an das CRM aus, Design und Seiten bleiben. Unser Werkzeug ImmoSync liest Objektdaten aus Propstack und onOffice. Felder, die es nur in einem System gibt, gleichen wir im Mapping ab.
